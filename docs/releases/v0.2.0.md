mado S3 Data Catalogのアクセストークンを、Settings → Access → Access Tokensの一つの一覧で管理できるようになりました。

## 変更点

- トークンの作成、名前・説明・権限・有効期限の編集、再発行、無効化・有効化、削除に対応しました。再発行すると旧トークンは即時に失効し、新しい値は一度だけ表示されます。
- 一つのトークンにDataLineageの参照・送信と容量メトリクスの取得を組み合わせて許可できます。
- Namespaceを検索し、一覧のチェックボックスで複数選択できます。Marquezと既存トークンから候補を取得し、未登録の名前も追加できます。全Namespaceへの許可は明示的に選びます。
- 日本語・英語の画面とドキュメントを更新しました。

## 互換性と更新手順

既存のトークン値、権限、Namespace、監査上の識別子を引き継ぎます。従来のService Accounts管理APIと画面URLも引き続き利用できます。

更新前にDBをバックアップし、**新しいAPIを起動する前に`db/migrations/038_access_tokens.sql`を適用してください**。古い版から更新する場合は、添付の`db/README.md`に従い、それ以前の未適用ファイルも順番に適用してください。

トークンの無効化を両方の入口で反映するため、`api-internal`と`api-lineage`を同じ版へ更新してください。無効化は再度有効にできますが、再発行と削除で失効した値は復元できません。

## 配布物

Linux amd64/arm64向けの`mado-api`、`mado-media-worker`、`mado-web`をGHCRで配布します。添付の`mado-v0.2.0.tar.gz`には、digest固定のCompose、設定例、DB更新ファイル、導入手順が入っています。SHA-256チェックサムとビルド証明も公開します。

互換Dataset Registryとその認証トークンは引き続き別途必要です。[ドキュメント](https://aida0710.github.io/mado-s3-datacatalog/)と[アクセストークンの仕様](https://github.com/aida0710/mado-s3-datacatalog/blob/v0.2.0/docs/access-tokens.md)を参照してください。
