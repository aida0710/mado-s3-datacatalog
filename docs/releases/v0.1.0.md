mado S3 Data Catalogの初回リリースです。複数のS3互換ストレージにあるデータを閲覧し、ファイルのプレビュー、README、共有ノート、データの来歴をチームで使えます。

## 主な機能

- 複数のS3互換ストレージを横断した閲覧、ダウンロード、共有リンク
- テキスト・画像・音声・動画とtar内のファイルのプレビュー
- ディレクトリのREADME、Team note、タグ、容量の推移、移送の見積もり
- データセットとバージョンの来歴、ML Trackingからのデータセット参照
- ローカルアカウント・OIDCによるログイン、操作権限、Service Account、監査ログ
- 日本語・英語の画面とドキュメント

## 配布物と導入

Linux amd64/arm64向けのコンテナをGHCRで配布します。

- `ghcr.io/aida0710/mado-api:v0.1.0`
- `ghcr.io/aida0710/mado-media-worker:v0.1.0`
- `ghcr.io/aida0710/mado-web:v0.1.0`

添付の`mado-v0.1.0.tar.gz`には、イメージをdigestで固定したCompose、設定例、DBの初期化・更新ファイル、導入手順が入っています。ソースのビルドは不要です。SHA-256のチェックサムとビルド証明も添付します。

[ドキュメント](https://aida0710.github.io/mado-s3-datacatalog/)を参照してください。Web UIは社内ネットワーク向けです。HTTPSの入口を別途用意し、添付のREADMEに従って初期管理者を作成してください。

## 初期リリースでの制限

本番構成には、互換Dataset Registryとその認証tokenが別途必要です。Registry本体はこの配布物に含めません。DataLineageのグラフにはMarquezを使います。仕様と対応範囲は[RegistryのAPI契約](https://github.com/aida0710/mado-s3-datacatalog/blob/v0.1.0/docs/registry-api-contract.md)を参照してください。

既存環境を更新するときはDBをバックアップし、添付の`db/README.md`に従って未適用のmigrationを順番に適用してください。
