# madoの使い方

madoは、複数のS3互換ストレージを横断して見るWebツールです。ブラウザからファイルを開き、ディレクトリのREADME、容量、データの来歴を確認できます。

このガイドの画面は、現行のmadoを公開用サンプルデータで撮影したものです。画像をクリックすると拡大できます。

## 管理者から案内されたURLでログインする

ブラウザでmadoのURLを開きます。SSOを使う環境ではSSOのボタンを押し、Local Userを使う環境では管理者から案内されたユーザー名とパスワードを入力します。初回のパスワード変更を求められたら、変更を済ませてください。

<Screenshot src="/screenshots/login.png" alt="Local UserとSSOを選べるログイン画面" caption="使えるログイン方法は、管理者の設定によって変わります。" />

## Storageから最初のファイルを開く

1. 左のサイドバーの **Storage** を開きます（スマホでは左上のメニューのボタンから開きます）。デフォルト接続があれば、その接続を自動で開きます。
2. バケットを選び、ディレクトリを辿ります。
3. ファイルの行をクリックすると、右側にプレビューが開きます。

接続を切り替えるときは、見出しの右にある **Connection** の選択欄を使います。接続がまだなければ、管理者が[ストレージを登録](../setup/connections.md)してください。

## 目的に合わせて画面を選ぶ

| 画面 | できること |
| --- | --- |
| Home | チーム全体の共有ノートを読む・編集する |
| Storage | ファイル、README、容量メトリクスを確認する |
| DataLineage | データと処理のつながりをグラフで辿る |
| Settings | 接続、機能、アカウント、アクセス権限を設定する |

まずは[バケットとファイルの探し方](./storage.md)へ。音声を比べたいときは[同期プレイヤー](./audio.md)、tar内のデータを見たいときは[アーカイブの閲覧](./archives.md)を参照してください。
